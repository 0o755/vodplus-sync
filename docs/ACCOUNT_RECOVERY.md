# 管理员密码与服务重置

重新部署只更新程序和数据库结构，不清空 D1。只要数据库已有管理员，访问时就是登录页；没有内置的默认 admin 账号或默认密码。

## 修改密码

登录后点击右上角管理员头像，或侧栏底部“账号与数据”。输入当前密码及两次新密码，新密码最低 5 位。成功后所有后台登录会话失效，需要重新登录；用户、设备、文件和分享数据保留。

## 服务重置菜单

1. 登录后台，点击左侧独立菜单 **服务重置**。
2. 查看页面说明的清空范围，点击 **清空全部数据并重置服务**。
3. 在确认弹窗中填写当前管理员密码，并输入大写 `RESET`。
4. 点击确认后，服务清空数据并回到管理员初始化页面。

全部通过网页完成，不需要执行终端命令、操作数据库控制台、删除数据库或重新创建 Worker。

重置包含管理员、人物、设备授权、文件内容及历史版本、观看和搜索记录、配置、分享接口与凭证、冲突、同步回执和日志。同步规则恢复默认。数据库表结构、迁移记录和 Cloudflare 资源保留。

此操作不能从后台撤销，建议提前备份。重置发生在同一个数据库事务中，执行失败会整体回滚；它不会由重新部署自动触发。

## 无法登录时

先确认使用原管理员账号和密码。显示登录页代表当前 D1 中已有管理员，并不代表存在默认的 admin 密码。

服务重置需要管理员登录与确认；不能仅凭公开访问地址匿名清空数据。如果原账号密码确实遗失，需要服务所有者先恢复管理员访问权限，再使用重置菜单。

## App 与线上诊断

服务重置只清空云端，不自动删除 App 本地文件和历史。原设备授权失效后，需要显式重新绑定，不能把旧人物的待同步队列自动改归新人物。

`GET /api/health` 返回公开表结构的就绪情况，不返回账号、设备或凭证。内部异常提供诊断码与请求编号；日志不记录完整 URL、SQL、令牌、设备码或密码。

如果旧日志还显示 `env.BUCKET` 或 R2 10085，先核对构建关联的完整仓库、分支和提交。当前版本仅使用 D1；新部署日志会打印 `[VodPlus Sync] source=...`，用于确认实际构建的提交。
