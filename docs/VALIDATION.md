- 管理接口匿名访问、初始化重复提交与 Origin 校验。
- 绑定码重复/并发消费、用户归属和停用检查；只传设备码以及旧 username 字段兼容。
- 文件大小、摘要及危险路径拒绝。
- 人物间文件和变更流隔离，设备 token 不能进入管理员接口。
- opId 重试、不一致请求体拒绝、并发版本冲突与候选保留。
- 目录移动保持身份、删除墓碑与显式恢复。
- 播放回看、旧会话拒绝覆盖。
- 分享密码、只读权限、子脚本鉴权、密码重置撤销 token。
- JSON 相对引用携带凭证，发布目录跟随稳定 ID。
- 公共文件独立复制及复制重试。
- 20 版 UI 窗口与长期离线旧内容下载。
- 100 条分页及固定 until 上界。
- 参考客户端提交响应丢失后保留队列、幂等重试并完成下载。
- 设备撤销、人物停用立即生效。
- 生成的多线路和 JSON 子资源鉴权，普通名称不被误改为 URL。
- 客户端拒绝跨人物待办，下载摘要错误不推进游标。

`npm run check` 编译检查服务端、前端和参考客户端模块。

`npm run build` 执行 Wrangler dry-run，验证入口、静态资源和 DB/ASSETS 绑定配置，不产生远端资源。
