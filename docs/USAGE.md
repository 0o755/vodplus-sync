# 使用说明

## 人物与设备

在“用户管理”创建人物，例如家人昵称。用户名可以重命名，内部 userId 保持不变，已有设备无需重新绑定。人物账号不具备后台管理权限。

点击“绑定设备”获得 10 分钟有效的一次性绑定码。在实现本协议的 App 中输入服务器地址、已有用户名、设备名称和绑定码。服务端返回该人物专属的设备凭证；App 应放入 Android Keystore 保护的存储。仅知道用户名无法访问数据。

“设备管理”可重命名设备或撤销访问。撤销不可直接重新启用，需要重新绑定。停用人物会同时阻止其设备同步与私有目录分享，但保留数据。

“最近在线”仅表示过去两分钟有请求，不承诺设备此刻仍在运行。App 主动请求同步接口即可更新活跃时间，不需要后台保活。

## 文件与目录

在“爬虫管理”选择人物或公共库。创建目录后上传脚本、配置或普通文件；云端只接收相对路径，不接受 Android 绝对路径。单文件最多 1,572,864 字节，即 1.5 MiB。

- 文本文件可直接编辑保存。二进制文件提供下载、移动和版本管理。
- “重命名 / 移动”输入完整的新相对路径。父目录必须已存在；ID 不变。目录移动包含当前存活子项，最多 80 项一次。
- “停用”保留内容。配置发布会立即排除停用项及停用目录的所有后代；设备接入必须按相同元数据处理扫描。
- “移入回收站”发布删除记录。勾选回收站后可以恢复，恢复创建新版本。删除目录的子项按父目录优先顺序逐项恢复。
- “历史版本”展示最近 20 版，恢复会创建新版本，仍须通过版本比较。
- “冲突候选”可以保留当前版本，或查看候选后采用。文件候选的内容仍在 R2；超过预览长度时可通过管理 API 下载完整内容审阅。
- “用户记录”列出观看历史、进度、搜索和配置记录，可查看内容、停用或删除。记录由接入后的设备生成。

公共库默认独立维护。在公共文件详情点“复制给用户”，选择人物和路径，即产生独立文件。公共文件以后修改，不会覆盖用户副本。这是第一版采用的默认策略，未来可以增加显式引用方式。

## 发布配置

首页点击“新建接口”，选择来源空间、发布目录、名称及至少 12 位分享密码。留空目录会发布这个文件空间的全部有效文件；不会发布用户记录、设备信息或同步 API。

分享目录与其稳定 ID 绑定。重命名后接口继续指向同一目录；删除或停用该目录会阻止访问，创建另一个同名目录不会接管旧分享。

两种分享入口：

1. **分享入口** `/s/<id>`：接收者打开网页输入密码，再复制配置 URL。
2. **复制配置 URL**：管理员签发 30 天有效的只读凭证链接，可直接交给接收者粘贴到 App 点播配置中。持有链接等于有读取权限，请按凭证保管。

修改接口密码、状态或名称都会撤销其全部旧凭证，需要重新获取配置 URL。停用人物也会阻止该人物的所有分享。

## 资源格式

- `.py`、`.js`、`.php` 作为 type=3 脚本站点，保留扩展名。多个目录生成为多线路配置。
- 非“直播配置”目录中的 `.json` 文件作为独立点播配置线路。请只在发布目录放实际配置，不要混放无关 JSON。
- 固定名为“直播配置”的目录下 `.txt`、`.m3u`、`.m3u8`、`.json` 生成直播入口。
- 配置 JSON 中的 `./script.py`、`../sibling.json` 或 `local://发布根相对路径/script.py` 会转换成受保护的文件 URL。`local://` 从人物文件空间根目录解释，目标仍须在发布范围内。
- 外部 HTTP(S) 地址保持不变；服务端不会代理外站或把分享 token 发给外站。脚本内部的 import、读取相邻文件等依赖不会改写，需脚本自身支持或以后增加加载器适配。
- 文件列表、配置、子线路及脚本下载全部鉴权。R2 bucket 不应额外开启公开域名。

旧版 ys 的 Apidog/Apifox 密码弹窗不会自动识别本服务。可先使用网页换取的带凭证 URL；专用 App 密码体验需接入 `POST /share/<id>/auth`，详见 App 接入文档。
