# 使用说明

## 人物与设备

在“用户管理”创建人物，例如家人昵称。用户名可以重命名，内部 userId 保持不变，已有设备无需重新绑定。人物账号不具备后台管理权限。

点击“绑定设备”获得 10 分钟有效的一次性设备码。在装有新版 App 的设备上点击“一键绑定”，自动填写服务器并绑定；Android 浏览器可使用兼容打开链接。手动绑定只需填写服务器和设备码，不需要用户名。用户由设备码确定，App 显示后台返回的当前名字。未安装 App 时先安装支持此入口的版本，复制码仍可使用。后台需以 HTTPS 打开才能一键绑定。

“设备管理”可重命名设备或撤销访问。撤销不可直接重新启用，需要重新绑定。停用人物会同时阻止其设备同步与私有目录分享，但保留数据。

“最近在线”仅表示过去两分钟有请求，不承诺设备此刻仍在运行。App 主动请求同步接口即可更新活跃时间，不需要后台保活。

点击设备名或“当前配置”，会打开四项配置弹窗：点播、直播、主题、壁纸。左侧是设备实际回报，右侧可修改待下发值；点击“清空”可下发空值。保存后显示待应用版本，只有 App 加载并回报后才显示已确认。

“实时取值”请求在线 App 重新采集，弹窗最多等待 60 秒；离线或旧 App 未接入时保留最后上报时间，不把旧值当作实时值。设备配置独立保存，不应通过 App 的普通人物配置同步传播到其他设备。

## 文件与目录

在“爬虫管理”选择人物或公共库。创建目录后上传脚本、配置或普通文件；云端只接收相对路径，不接受 Android 绝对路径。单文件最多 1,572,864 字节，即 1.5 MiB。

- 每一级都先显示目录、再显示文件，默认按名称自然排序；工具栏可选择名称升/降序、最近修改、大小和类型。目录默认收起，支持“全部展开 / 全部收起”；名称后的“＋ / −”仍可单独控制。搜索会临时展开匹配路径，清空搜索后恢复原状态。黄色文件夹与各后缀对应的文件图标会区分资源类型。大屏在文件右侧显示操作；小屏点击“操作”展开菜单。
- 点击文件标题打开编辑弹窗。文本可直接保存，二进制文件可用“替换文件”上传新版本。
- “重命名 / 移动”输入完整的新相对路径。父目录必须已存在；ID 不变。目录移动包含当前存活子项，最多 80 项一次。
- “停用”保留内容。配置发布会立即排除停用项及停用目录的所有后代；设备接入必须按相同元数据处理扫描。
- “移入回收站”发布删除记录。勾选回收站后可以恢复，恢复创建新版本。删除目录的子项按父目录优先顺序逐项恢复。
- “历史版本”展示最近 20 版，恢复会创建新版本，仍须通过版本比较。
- “冲突候选”可以保留当前版本，或查看候选后采用。文件候选的内容仍在 D1；超过预览长度时可通过管理 API 下载完整内容审阅。
- “用户记录”列出观看历史、进度、搜索和配置记录，可查看内容、停用或删除。记录由接入后的设备生成。

公共库默认独立维护。在公共文件详情点“复制给用户”，选择人物和路径，即产生独立文件。公共文件以后修改，不会覆盖用户副本。这是第一版采用的默认策略，未来可以增加显式引用方式。

## 拖放和批量上传

把文件拖到文件页面，或点击“上传文件”，都会打开同一上传弹窗。可选择根目录或任意已有目录，并预览每个文件的目标路径。

默认同名自动重命名，例如 a.py → a (1).py；选择覆盖时沿用现有文件 ID、保留历史版本。目录同名和同批次重复名称始终避让。文件字节最多三路并发，元数据按顺序保存；过时版本返回冲突，不强行覆盖别人刚更新的内容。

每项显示完成或失败原因；可停止后续上传、重试未完成项。已成功保存的项目不会撤销。超过 1.5 MiB 或不符合人物同步规则的文件会明确失败。拖放当前支持文件，不递归导入整个文件夹。

## 默认同步文件类型

进入“爬虫管理 → 同步规则”。默认后缀为 py、js、txt、json、m3u8、jar、php、html，并允许无后缀文件。可输入逗号或空格分隔的后缀，后端会转为小写并去掉开头的点。

文件名按最后一个点识别后缀；例如 archive.tar.gz 为 gz，.hide 视为无后缀。默认排除 `_cache`、`__pycache__`、`pycache` 三种目录名，忽略大小写、匹配任意层级，其子树也不参与同步；其他目录仍同步。目录规则不排除同名的普通文件。规则是所有用户共用的默认设置；人物空间新文件和内容更新受限，公共爬虫库的独立发布不受影响。

更改规则不会删除云端或设备上的旧文件。设备下一轮读取规则，版本变化后重新核对完整变更流；不符合规则的本地文件不能被当作删除。已存旧类型仍可移动、停用、删除和读取历史。

## 管理员与恢复初始状态

右上角头像或侧栏“账号与数据”提供修改密码和完整重置。改密要求当前密码，新密码最低 5 位；重置要求当前密码及输入 `RESET`，清空云端业务数据后重新创建管理员。重新部署不会自动重置管理员。

忘记原密码、无法登录时，可在登录页打开“账号与重置说明”，通过自己的 Cloudflare D1 控制台执行重置。完整步骤和清空范围见 [账号恢复](ACCOUNT_RECOVERY.md)。本次功能实现不代表已经清空你的线上数据。

## 发布配置

首页点击“新建接口”，填写来源空间、发布目录和名称。密码可留空（公开访问），设置时至少 5 位；链接永久有效。留空目录会发布这个文件空间的全部有效文件；不会发布用户记录、设备信息或同步 API。

分享目录与其稳定 ID 绑定。重命名后接口继续指向同一目录；删除或停用该目录会阻止访问，创建另一个同名目录不会接管旧分享。

两种分享入口：

1. **分享入口** `/s/<id>`：公开接口直接展示配置 URL；设置密码的接口输入密码后获取 URL。
2. **复制配置**：点击即复制永久链接，无额外确认弹窗。公开接口使用不带 token 的固定 URL；密码接口签发永久只读凭证链接。

接口设置可保留密码、设置新密码或取消密码。修改密码会撤销旧授权；改名称不会影响已有链接。停用接口/人物会阻止访问，重新启用后原链接可继续使用。

## 资源格式

- `.py`、`.js`、`.php` 作为 type=3 脚本站点，保留扩展名。多个目录生成为多线路配置。
- 非“直播配置”目录中的 `.json` 文件作为独立点播配置线路。请只在发布目录放实际配置，不要混放无关 JSON。
- 固定名为“直播配置”的目录下 `.txt`、`.m3u`、`.m3u8`、`.json` 生成直播入口。
- 配置 JSON 中的 `./script.py`、`../sibling.json` 或 `local://发布根相对路径/script.py` 会转换成受保护的文件 URL。`local://` 从人物文件空间根目录解释，目标仍须在发布范围内。
- 外部 HTTP(S) 地址保持不变；服务端不会代理外站或把分享 token 发给外站。脚本内部的 import、读取相邻文件等依赖不会改写，需脚本自身支持或以后增加加载器适配。
- 文件列表、配置、子线路及脚本下载全部鉴权。D1 中的文件内容只能通过这些鉴权接口读取，无需额外开通存储服务。

旧版 ys 的 Apidog/Apifox 密码弹窗不会自动识别本服务。可先使用网页换取的带凭证 URL；专用 App 密码体验需接入 `POST /share/<id>/auth`，详见 App 接入文档。
