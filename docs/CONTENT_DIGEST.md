# 内容摘要

摘要用于判断客户端内容是否与云端一致。文件对原始字节计算 SHA-256，输出 64 位小写十六进制字符串。

JSON 使用下述 `json-sha256-v1` 编码，再计算 SHA-256。它对属性顺序、JSON 空白及字符转义形式不敏感。

## 编码规则

各部分直接连接，不加入空白或分隔符之外的额外字符。最终文本使用 UTF-8 编码。

| JSON 类型 | 编码 |
| --- | --- |
| null | `n` |
| false | `f` |
| true | `t` |
| number | `d` + IEEE 754 binary64 大端字节的 16 位小写十六进制表示 |
| string | `s` + UTF-8 字节长度 + `:` + 字符串原文 |
| array | `a` + 元素数量 + `:` + 按顺序编码各元素 |
| object | `o` + 属性数量 + `:` + 依次编码属性名字符串及属性值 |

对象属性名按 UTF-16 代码单元升序排列。长度和数量使用无前导零的十进制整数。字符串原文不做 JSON 转义，也不进行 Unicode 规范化。

数字先转换为 binary64，负零按正零处理，不接受非有限值。字符串和属性名必须是有效 Unicode，不接受孤立代理字符。

## 示例

| value | 编码文本 |
| --- | --- |
| `null` | `n` |
| `1` | `d3ff0000000000000` |
| `1.5` | `d3ff8000000000000` |
| `"Hello"` | `s5:Hello` |
| `"你好🌍"` | `s10:你好🌍` |
| `["a",1]` | `a2:s1:ad3ff0000000000000` |
| `{"b":2,"a":"x"}` | `o2:s1:as1:xs1:bd4000000000000000` |

## 校验向量

| value | SHA-256 |
| --- | --- |
| `null` | `1b16b1df538ba12dc3f97edbb85caa7050d46c148134290feba80f8236c83db9` |
| `"Hello"` | `3698dca7681f48f88f5ad97df04ad2ba310fd4bd34b3f3af53f918775798a827` |
| `"你好🌍"` | `fbbe9eb69560fbdb0395c36975c52291ed99ea06b6a813af72c70e0d63943d79` |
| `{"b":2,"a":"x"}` | `39e144ee963971610cb872fd4a7f10fdce56af3b67cc30d693a61aa6315b2976` |

JavaScript 实现：[content-digest.js](../src/lib/content-digest.js)。SDK 的完整推送会自动调用摘要函数。
